# Гіпотеза Колатца — паралельні обчислення

## Опис
Реалізація обчислення послідовності Колатца для чисел від 1 до 10 000 000
з використанням паралельних обчислень (ThreadPool).

## Структура проєкту
```
.
├── collatz_parallel.py   # основний код
├── requirements.txt      # залежності
├── README.md             # цей файл
├── .gitignore
└── .gitkeep
```

## Запуск

**Вимоги:** Python 3.8+, лише стандартна бібліотека.

```bash
python collatz_parallel.py
```

Щоб задати кількість потоків вручну — змінити у файлі:
```python
NUM_THREADS = 8
```

## Що виводить програма
- Загальний час обчислень
- Середня кількість кроків для виродження в 1
- Максимальна кількість кроків та відповідне число
- Перші 10 чисел з кількістю кроків

## Відомі обмеження
- Python GIL обмежує справжній паралелізм для CPU-задач.
  Для максимальної швидкості можна замінити `ThreadPool` на `multiprocessing.Pool` — логіка коду не змінюється.
- Час виконання залежить від процесора та кількості потоків.
